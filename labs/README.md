# Лабораторные по КМОИ (1–14)

Зависимости: `pip install opencv-python numpy matplotlib`.

Каждая лаба запускается отдельно:

```
python labNN_*.py --demo                # синтетический пример, файл не нужен
python labNN_*.py --image file.png      # свой файл
python run_all.py                       # все 14 подряд (графики в out/)
```

| № | Файл | Тема |
|---|------|------|
| 1 | `lab01_normalization.py` | яркостная нормализация (LUT), устойчивый вариант, цвет |
| 2 | `lab02_equalization.py` | эквализация (формула методички и вариант OpenCV), CLAHE |
| 3 | `lab03_profiles.py` | профили яркости, билинейная интерполяция |
| 4 | `lab04_projections.py` | проекции, строки текста, угол наклона |
| 5 | `lab05_binarization.py` | порог, Оцу, ISODATA, Саувола |
| 6 | `lab06_nonlinear_filtering.py` | ранговые фильтры, минимакс, нормализация фона |
| 7 | `lab07_linear_filtering.py` | свёртка/корреляция, Гаусс, Собель, Лапласиан |
| 8 | `lab08_hough.py` | Хаф для прямых и окружностей |
| 9 | `lab09_binary_segmentation.py` | разметка связных компонент |
| 10 | `lab10_halftone_segmentation.py` | пороги по гистограмме, k-means, наращивание областей |
| 11 | `lab11_gray_contours.py` | Робертс/Прюитт/Собель, Канни, LoG |
| 12 | `lab12_binary_contours.py` | граничные пиксели, прослеживание Мура, цепной код |
| 13 | `lab13_morphology_serra.py` | эрозия/дилатация/открытие/закрытие, фон, скелет |
| 14 | `lab14_task.py` | сквозной конвейер (шаблон: текст задачи неизвестен) |

`common.py` — только ввод/вывод, шум, метрики и тестовые изображения.
`conspect/` — опорный конспект 80/20 (HTML и PDF).

В каждой лабе: проверка файла, ручная реализация ядра алгоритма, сравнение с OpenCV,
замер времени, тест на шум, график. Запуск без `--image` использует демо-данные.
