0. Сквозные темы (спрашивают в каждой лабе)

  • Тип данных. Изображение: uint8, значения 0–255. Промежуточные вычисления делать во float (float32/64): в uint8 произведение переполняется по модулю 256 (NumPy), а в OpenCV насыщается (260 → 255). Целочисленное деление и astype(uint8) усекают, нужно np.rint (округление) и clip(0,255).
  • Краевые пиксели. Окно выходит за границу: reflect (BORDER_REFLECT_101, по умолчанию в OpenCV), replicate (повтор края), constant (нули). Выбор меняет результат только у границы шириной k/2. Для min-фильтра/эрозии «за краем» подставляют +∞ (255).
  • Цвет. OpenCV хранит BGR, Matplotlib ждёт RGB. Gray = 0.299R + 0.587G + 0.114B (чувствительность глаза). Операции над яркостью делают в HSV (канал V) или YCrCb/Lab (Y, L), иначе сдвигается баланс цветов.
  • Свёртка и корреляция. Свёртка переворачивает ядро на 180°, корреляция нет. cv2.filter2D — корреляция. Для симметричных ядер совпадают; для Собеля отличаются знаком.
  • Сложность. Поточечное (LUT): O(N). Окно k×k: O(N·k²). Разделимое ядро: O(N·2k). Ранговые фильтры: сверхлинейно по размеру апертуры (методичка). Интегральное изображение: O(N) независимо от размера окна. N = H·W.
  • Шум. Гауссов (аддитивный) → усреднение/Гаусс. Импульсный («соль-перец») → медиана. Усреднение w независимых отсчётов снижает СКО шума в √w раз. Оценка качества: MSE, PSNR = 10·lg(255²/MSE), IoU для масок.
  • Что должно быть в каждой лабе: загрузка с проверкой файла · цветовое пространство с обоснованием · алгоритм (≥70 % вручную) · subplot промежуточных этапов · сравнение с OpenCV · время · тест на шум.

1. Нормализация (яркостная)

Суть и формула

Линейное растяжение реального диапазона яркостей [Imin, Imax] на [0, 255] (адаптивная гистограммная обработка).

LUT[i] = 255 · (i − Imin) / (Imax − Imin), Imin ≤ i ≤ Imax

Вывод: ищем f(i) = a·i + b, f(Imin)=0, f(Imax)=255 → a = 255/(Imax−Imin), b = −a·Imin. Матрично: I' = a·I + b·1.

Свойства

  • Строго монотонна ⇒ сохраняется порядок яркостей; a ≥ 1 ⇒ разные уровни остаются разными (без потери различий).
  • Разности яркостей ×a ⇒ контраст ×a (σ' = a·σ); гистограмма растягивается, форма не меняется.
  • Сложность O(N) (поиск min/max + применение LUT).
Ловушки. (1) min(Hist(Im)) в методичке — минимальная яркость на изображении, не минимум счётчиков. (2) Один выброс (пиксель 255) задаёт Imax: диапазон [100,140] уходит в [0,66], пиксель 120 → 33. Лечится перцентилями (1–99 %) или медианой до нормализации; цена — насыщение хвостов, потеря взаимной однозначности. (3) Imax = Imin → деление на 0: вернуть копию. (4) Цвет: по каналам нельзя (сдвиг цвета), нормализовать V. (5) Не путать с «нормализацией фона» (гл. 3.3: вычитание карты фона).

Вопросы:

  • Почему float, а не uint8? — переполнение (x−Imin)·255 и усечение 32,9→32.
  • Чем отличается от эквализации? — линейна и обратима; эквализация нелинейна и может склеивать уровни.

2. Эквализация гистограммы

Суть и формула

Яркость заменяется нормированной кумулятивной гистограммой (CDF): число пикселей на разных уровнях «выравнивается».

LUT[i] = 255 · SUM(Hist, Imin, i) / SUM(Hist, Imin, Imax)

OpenCV: (CDF(i) − CDFmin) / (N − CDFmin) · 255 — самый тёмный пиксель ровно в 0.

Смысл

  • Если яркость — СВ с плотностью p(r), то s = F(r) (интегральная функция) имеет равномерное распределение: отсюда CDF как таблица отображения. Дискретно гистограмма получается лишь приблизительно плоской.
  • Плотные участки гистограммы растягиваются сильнее (крутой наклон CDF), редкие — сжимаются. Видны «проявившиеся» детали.
  • Если все градации в [Imin, Imax] присутствуют ≈ равномерно, результат почти не отличить от нормализации (методичка); если многих градаций нет — эквализация использует диапазон лучше.
Ловушки. Усиливает шум в однородных областях (CLAHE — эквализация по плиткам с ограничением контраста). Необратима: уровни могут слипаться. Для цвета — по V. Константное изображение → вернуть копию. Сумма от Imin или от 0 — одно и то же, ниже Imin гистограмма пуста.

Вопросы:

  • Почему гистограмма после эквализации не идеально плоская? — дискретность, уровни не делятся.
  • Сложность? — O(N) на гистограмму + O(256) на CDF + O(N) на применение.

3. Профили яркости

Суть и формулы

Профиль — график яркости вдоль линии: P(t) = I(x₀ + t·dx, y₀ + t·dy). Горизонтальный = строка, вертикальный = столбец. Вдоль наклонной линии координаты нецелые → интерполяция.

I(x,y) = (1−wy)[(1−wx)I₀₀ + wx·I₁₀] + wy[(1−wx)I₀₁ + wx·I₁₁]

wx, wy — дробные части координат (билинейная). Ближайший сосед быстрее, но даёт «лесенку».

Применение и параметры

  • Перепады профиля = границы: производная P[i+1] − P[i] максимальна на перепаде. Расстояние между перепадами = размер объекта.
  • Ширина w: усреднение поперёк линии снижает шум в √w раз, но размывает тонкие детали поперёк.
  • Шаг отсчётов ≈ 1 пиксель; длина профиля = ⌈|p₁−p₀|⌉ + 1.
  • Профиль помогает выбрать порог бинаризации и увидеть неравномерность освещения.
Ловушки. Выход за изображение → зажать координаты. Совпадающие концы отрезка → ошибка. Профиль по зашумлённому изображению надо усреднять, иначе производная — сплошной шум.

4. Проекции

Формулы

PH(y) = Σₓ I(x,y) PV(x) = Σᵧ I(x,y)

Для бинарного изображения (объект = 1) — число пикселей объекта в строке/столбце. Обобщение на угол θ — преобразование Радона (его дискретный «двойник» — Хаф).

Применение

  • Строки текста: впадины PH(y) (≈0) разделяют строки; символы: впадины PV(x) внутри строки.
  • Угол наклона: перебрать повороты, взять тот, при котором дисперсия PH максимальна (острые пики и глубокие впадины).
  • Размеры/положение объекта: границы, где проекция выходит из нуля.
Ловушки. Складывать в int64 (сумма uint8 по строке переполнит). Объект должен быть «1»: для тёмного текста инвертировать бинарку. Две проекции не восстанавливают изображение (нужно много углов, томография). Шум в бинарке даёт ложные «пики». Сложность O(N); поиск угла O(N·число углов).

5. Бинаризация

Методы

  • Глобальный порог: B = 255, если I > T. Порог — по гистограмме: бимодальная → во впадине между модами (методичка: «адаптивная бинаризация»); унимодальная → яркостно-однородное изображение, порога нет.
  • Оцу: максимум межклассовой дисперсии; ω(t) — доля пикселей ≤ t, μ(t) — накопленное среднее.
    • σ²_b(t) = (μ_T·ω(t) − μ(t))² / (ω(t)·(1 − ω(t))), t* = argmax σ²_b
  • ISODATA: T ← (mean(I≤T) + mean(I>T))/2 до сходимости.
  • Локальный (Саувола): T(x,y) = m·(1 + k·(s/R − 1)), m, s — среднее и СКО в окне; R=128, k≈0,2. Статистики окна — через интегральное изображение: S = II[y+w,x+w] − II[y,x+w] − II[y+w,x] + II[y,x], O(N).
Ловушки. Градиент освещения ломает глобальный порог (в тесте IoU 0,09 против 0,995 у Саувола). Окно локального метода ≥ 2× размера объекта, иначе внутри крупного объекта m ≈ I и он «дырявится». Саувола рассчитан на тёмный объект на светлом (иначе инвертировать). Оцу предполагает бимодальность. Шум → сначала медиана.

Вопрос:

  • Почему Оцу = минимум внутриклассовой дисперсии? — σ²_total = σ²_within + σ²_between, а σ²_total не зависит от t.

6. Нелинейная полутоновая фильтрация

Суть

Ранговые фильтры: значения в окне k×k упорядочиваются, на выход — элемент заданного ранга: min (0), медиана (k²/2), max (k²−1).

  • Медиана убирает импульсный шум и сохраняет перепады (не размывает границы, не создаёт новых значений яркости). Нелинейна. Тонкие линии и острые углы тоньше k/2 стирает.
  • Минимакс = min, затем max (2 прохода): убирает светлые выбросы меньше окна; максимин — тёмные. Против биполярного импульсного шума выигрыша у медианы нет (методичка).
  • Размер апертуры: больше k → сильнее подавление, больше искажение геометрии, время растёт сверхлинейно. min/max разделимы (min по строкам, потом по столбцам) — O(N·k).

Нормализация фона (методичка, гл. 3.3)

1) фильтр малой апертуры (3×3…5×5) убирает импульсный шум; 2) фильтр большой апертуры (до 35×35) подавляет объект, оставляя фон; 3) вычитание карты фона из изображения шага 1 → сегментация по яркости. Для минимакса апертура нужна примерно вдвое меньше, чем для медианы. Объём вычислений растёт ∝ квадрату апертуры. Последовательность фильтров выбирает знак контраста (светлые/тёмные объекты).

Ловушки. Апертура большого фильтра должна быть больше объекта. Края: зеркальное дополнение. Медиана — по значениям, а не среднее; чётные окна не используют.

7. Линейная фильтрация в пространственной области

Формулы

(I∗K)(x,y) = Σᵢ Σⱼ K(i,j)·I(x−i, y−j)
  • Усреднение k×k: все веса 1/k². Гаусс: g(x) ∝ exp(−x²/2σ²), нормирован на 1; 2D = внешнее произведение двух 1D ядер ⇒ разделим: O(N·2k) вместо O(N·k²).
  • Собель gx = [[−1,0,1],[−2,0,2],[−1,0,1]] — производная по x и сглаживание по y; Прюитт — без весов 2.
  • Лапласиан [[0,1,0],[1,−4,1],[0,1,0]] — вторая производная; резкость = I − ∇²I → ядро с 5 в центре.

Правило сумм

Сглаживающее ядро: сумма весов = 1 (средняя яркость не меняется). Дифференцирующее: сумма = 0 (на плоском участке отклик 0).

Ловушки. Свёртка ≠ корреляция (перевернуть ядро). Результат дифференцирующего ядра отрицателен → хранить в float, при выводе брать модуль. Лапласиан усиливает шум (вторая производная). Гаусс σ ↔ размер ядра ≈ 6σ+1. Больше ядро → сильнее сглаживание и размытие границ. Теорема о свёртке: свёртка в пространстве = произведение спектров.

8. Преобразование Хафа

Формулы

ρ = x·cosθ + y·sinθ, θ ∈ [0°, 180°), |ρ| ≤ √(H²+W²)
  • Точка контура → синусоида в плоскости (θ, ρ) («голосует» за все прямые через неё). Пересечение синусоид = общая прямая; пик аккумулятора = найденная прямая.
  • Почему не y = kx + b? — у вертикали k = ∞. Нормальная параметризация ограничена.
  • Окружность известного радиуса: центр (a,b) = (x − r·cosφ, y − r·sinφ). Неизвестный r → 3D аккумулятор → дорого; обычно перебирают диапазон радиусов.

Параметры

  • Шаг θ, ρ: меньше — точнее, но дольше и пики «рассыпаются»; больше — быстрее, но прямые сливаются.
  • Порог пика, подавление немаксимумов (иначе вокруг пика облако соседей). Сложность O(N_контур · N_θ), память N_ρ × N_θ.
Ловушки. Вход — бинарная карта контуров (Canny), а не исходное изображение. Шум → фоновый «туман» в аккумуляторе; смягчается размытием перед Canny. θ и θ+180° дают одну прямую с ρ противоположного знака.

9. Сегментация бинарных изображений

Суть

Разметка связных компонент: каждому объекту — своя метка. Связность: 4 (стороны) или 8 (стороны + диагонали). Если объекты 8-связные, фон надо считать 4-связным (и наоборот), иначе возникает парадокс (диагональ «пересекает» диагональ).

Алгоритм (два прохода + union-find)

  • Проход 1 (растровый): смотрим уже обработанных соседей (слева, сверху; при 8: ещё две верхние диагонали). Нет соседей → новая метка. Иначе берём минимальную и записываем эквивалентность остальных (union).
  • Проход 2: каждая метка → корень её класса → последовательные номера 1…n.
  • Сложность O(N·α(N)) ≈ O(N). Альтернатива: поиск в ширину/глубину от каждого пикселя.

Свойства объектов

Площадь, центр масс (x̄ = Σx/A), bbox, периметр, компактность 4πA/P².

Ловушки. «Соль-перец» → сотни ложных компонент: фильтр по площади или морфология. 4 и 8 дают разное число объектов на диагональных касаниях. Метки в разных реализациях отличаются перестановкой — сравнивать как разбиения.

10. Сегментация полутоновых изображений

Яркостная сегментация (методичка)

  • Мода — «горб» гистограммы. Унимодальная = яркостно-однородное; бимодальная = «фон + объект» → порог во впадине (адаптивная бинаризация); мультимодальная — сложнее. Число мод = число яркостных классов, пороги — минимумы между модами.
  • Гистограмму сглаживают (гауссом σ≈3), иначе шум порождает ложные моды; ограничивают минимальную высоту и расстояние между модами.
  • k-means (Ллойд): назначить пиксель ближайшему центру → центр = среднее своих → повторять. Минимизирует Σ‖I − c‖², сходится к локальному минимуму; чувствителен к инициализации.
  • Наращивание областей: от затравки присоединять соседей с |I − среднее области| ≤ tol.
  • Текстурная сегментация: признаки по окну (локальная дисперсия, отклики фильтров), затем кластеризация.
Ловушки. Градиент освещения размывает моды. Шум: перед порогами — медиана (без неё моды расщепляются: в тесте σ=30 было 5 мод вместо 3, точность 0,45 → 0,99). Переходные пиксели границ попадают не в тот класс. Порог по гистограмме не использует пространственную информацию.

11. Контуры на полутоновых изображениях

Идея

Контур — резкий перепад яркости ⇒ максимум модуля первой производной (градиента) или нуль второй производной.

|G| = √(gx²+gy²) (или |gx|+|gy|), направление = atan2(gy, gx)
  • Робертс 2×2 (диагональные разности) — быстро, очень шумит. Прюитт, Собель 3×3 — сглаживание поперёк направления дифференцирования. Градиент ⊥ контуру.
  • Лапласиан/LoG: контур = смена знака отклика; LoG = Гаусс + Лапласиан, ядро сумма 0.
  • Канни: 1) Гаусс; 2) градиент; 3) подавление немаксимумов вдоль градиента (утоньшение до 1 пикселя); 4) гистерезис: слабые пиксели (≥ low) остаются, только если связаны с сильным (≥ high).
Ловушки. Производная усиливает шум → сглаживать до дифференцирования; σ — компромисс между подавлением шума и точностью локализации. Порог слишком низкий → «трава», слишком высокий → разрывы. Квантование угла до 4 направлений в NMS. Контур по порогу градиента толстый, по NMS — тонкий.

Вопрос: «А почему именно производная?» — перепад яркости = экстремум скорости её изменения.

12. Контуры на бинарных изображениях

Методы

  • Граничные пиксели: B = A − (A ⊖ крест). Эрозия крестом даёт тонкую 8-связную границу, эрозия 3×3 — 4-связную. Это набор точек, а не упорядоченная кривая.
  • Прослеживание Мура: из верхнего левого пикселя объекта обходить соседей по часовой стрелке, начиная с «пикселя возврата» (фона); первый пиксель объекта — следующая точка контура. Критерий Джейкоба: остановка, когда снова вышли из старта тем же ходом (простое «вернулись в старт» ошибается на тонких перемычках).
  • Цепной код Фримана (8 направлений). Периметр: чётные коды = 1, нечётные = √2. Площадь многоугольника по формуле шнуровки (меньше числа пикселей: считается по центрам).
Ловушки. Периметр катастрофически чувствителен к шуму (2 % шума: 7 контуров → 681). Внешний контур и контуры дыр — разные вещи (RETR_EXTERNAL не возвращает объекты внутри дыр). Край кадра = фон. Изолированный пиксель — контур из одной точки.

13. Математическая морфология Серра

Операции (B — структурирующий элемент)

(A⊖B)(x) = min_{b∈B} A(x+b) (A⊕B)(x) = max_{b∈B} A(x−b)
  • Эрозия сжимает (убирает светлое меньше B), дилатация расширяет (заполняет тёмное меньше B). Двойственны: A ⊕ B = (Aᶜ ⊖ B̌)ᶜ. Для бинарного — И / ИЛИ.
  • Открытие A∘B = (A⊖B)⊕B: убирает объекты меньше B, форму крупных сохраняет, антиэкстенсивно (A∘B ⊆ A). Закрытие A•B = (A⊕B)⊖B: заполняет дыры и разрывы, экстенсивно. Оба идемпотентны: (A∘B)∘B = A∘B.
  • Градиент = дилатация − эрозия. Top-hat = A − A∘B (светлые детали), black-hat = A•B − A. Hit-or-miss — поиск шаблона. Скелет Лантуэжуля: ∪ₖ [(A⊖kB) − ((A⊖kB)∘B)].
  • Нормализация фона (методичка): два СЭ: B₁ — маленький (подходит под самый малый объект, отсекает импульсный шум), B₂ — большой (подавляет отклик любого объекта). Объекты = A∘B₁ − A∘B₂.
Ловушки. Форма СЭ (крест, квадрат, круг) определяет, какие объекты исчезают. Дилатация использует отражённый СЭ. Открытие большим СЭ «затемняется» одним тёмным пикселем → сначала малым СЭ убрать шум обоих знаков (open-close). Сложность O(N·|B|). «Открытие» ≠ «эрозия»: форма сохраняется.

14. Решение задачи (шаблон ответа)

Текст задачи в списке не указан; ниже логика защиты любого «сквозного» задания.

  1. Постановка: что на входе (шум, освещение, размер объектов), что на выходе (число, площади, координаты).
  2. Модель изображения: объект светлее/темнее, форма, диапазон размеров, тип шума.
  3. Конвейер (порядок важен): подавление шума (медиана) → нормализация фона/освещения → бинаризация (Оцу или локальная) → морфология (убрать остатки, заполнить дыры) → разметка компонент → фильтр по площади → измерения.
  4. Параметры из геометрии: окно фона > крупнейшего объекта; min_area ≈ ¼ площади наименьшего объекта; СЭ меньше самого узкого.
  5. Проверка: число объектов, IoU с эталоном, тест на шум и на смену освещения, время по этапам.
  6. Ограничения: касающиеся объекты сливаются (разделить watershed/эрозией), нет учёта текстуры.
